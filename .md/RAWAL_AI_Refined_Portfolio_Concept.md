# RAWAL.AI --- Refined Interactive AI/ML Engineer Portfolio

## Core Concept

Build the portfolio as an **AI system coming to life** rather than a
traditional developer resume.

The visual story is:

**Data → Model → Training → Inference → Deployment**

The entire website revolves around one persistent **3D neural network /
AI core** that transforms as the visitor scrolls.

> **Don't make it feel like a "3D portfolio." Make it feel like a real
> AI system that happens to be your portfolio.**


``` text
SYSTEM ONLINE

[ ENTER SYSTEM ]
```

``` text
0%     Black void
       ↓

       ↓
40%    System logs execute
       ↓
60%    Neural particles appear
       ↓
80%    Neural network forms
       ↓
```

Instead of a simple fade:

``` text
BLACK VOID
    ↓

    ↓
```

# 18. PERFORMANCE ARCHITECTURE

The 3D layer should enhance the website, not become a performance
problem.

## Targets

``` text
≤ 50 active nodes
Instanced geometry
DPR capped at 2
Lazy 3D loading
Simplified mobile scene
Reduced-motion mode
```

## Progressive Loading

``` text
HTML CONTENT
     ↓
IMMEDIATE

3D ENGINE
     ↓
LOAD LAZILY

SHADERS / ASSETS
     ↓
LOAD WHEN NEEDED
```

The content should remain useful even if WebGL fails.

------------------------------------------------------------------------

# 22. DATA-DRIVEN DESIGN

Don't hard-code project information directly into 3D components.

Use data objects.

Example:

``` js
const projects = [
  {
    name: "FormAnchor",
    category: "Automation",
    technologies: [
      "React",
      "TypeScript",
      "Chrome Extension"
    ],
    pipeline: [
      "Spreadsheet",
      "Extension",
      "Form Fill",
      "Automation",
      "Done"
    ]
  },
  {
    name: "Expense Tracker MCP",
    category: "AI / MCP",
    technologies: [
      "Python",
      "MCP",
      "PostgreSQL",
      "LLM"
    ],
    pipeline: [
      "NL Input",
      "Intent Parser",
      "MCP",
      "PostgreSQL",
      "Response"
    ]
  }
];
```

Then the 3D project nodes can automatically generate themselves from the
data.

# 23. RECRUITER-FIRST DESIGN

The biggest danger of an experimental portfolio is:

> "This looks amazing, but what does this person actually do?"

Solve that explicitly.

Every major section should have a readable content layer.

Example:

``` text
┌───────────────────────────────────┐
│ FEATURE EXTRACTION                │
│                                   │
│ AI / ML ENGINEERING               │
│                                   │

│ LLMs · RAG · Computer Vision      │
│                                   │
│ [ VIEW SKILLS ]                   │
└───────────────────────────────────┘
```

The 3D provides the experience.

The text provides the information.
